# 词典目录

## 最快用法

把词典放进当前 `dictionaries/` 目录，再执行下面任一操作：

1. 网页打开「词典管理」，点击「重新扫描目录」；或
2. 重启服务（`npm run dev` / `npm start`）；或
3. 在项目目录运行 `npm run dict:import`。

导入结果保存在 `data/dictionaries.db`。未发生变化的文件会按指纹跳过；替换或更新源文件后，再扫描会自动重新导入。

## 文件怎么放

### Yomitan 词典

保持下载到的 zip 原样，不要解压：

```text
dictionaries/
└─ JMdict.zip
```

### 非 Yomitan 词典（MDict）

> **推荐：每部词典单独新建一个文件夹。** 将 `.mdx` 和它的配套 `.css` 放进这个文件夹；有 `.mdd` 时也放在一起。不要把多部 MDX 和多个 CSS 混放在 `dictionaries/` 根目录。

推荐结构：

```text
dictionaries/
└─ 明镜日汉双解辞典/
   ├─ 明镜日汉双解辞典.mdx
   ├─ mjrhsjcd.css                  # 可选：排版样式
   ├─ 明镜日汉双解辞典.mdd         # 可选：图片、音频等资源
   └─ 明镜日汉双解辞典.1.mdd       # 可选：分卷资源
```

配对规则：

- `.css` 与 `.mdx` 同名时优先使用；目录里只有一个 CSS 时也会自动配对。
- `.mdd` 应与 `.mdx` 同名，也支持 `.1.mdd`、`.2.mdd` 这样的分卷名称。
- 扫描器会递归查找最多四层子目录。
- 每个子目录最好只放一部 MDX；这样后续直接修改它旁边唯一的 CSS 即可调整显示效果，也不会配错样式。

如果下载的是“包含 `.mdx`、`.css`、`.mdd` 的 zip”，也可以不解压，直接放进 `dictionaries/`。

### 导入目录外的 MDX

不想复制文件时，可以传入绝对路径：

```bash
npm run dict:import -- "D:\\DOC\\JP_Dict\\某词典\\某词典.mdx"
```

命令行可一次传入多个 `.mdx` 或 `.zip` 文件。

## 支持的格式

### Yomitan / Yomichan

格式 v1 与 v3，包括：

| 类型 | 文件 | 用途 |
| --- | --- | --- |
| 词条 | `term_bank_*.json` | 释义、词性标签、结构化内容、内嵌图片 |
| 词条元数据 | `term_meta_bank_*.json` | 声调（pitch）、词频（freq） |
| 汉字 | `kanji_bank_*.json` | 音读、训读、字义、笔画等 |
| 标签 | `tag_bank_*.json` | 标签的分类与说明 |

### MDict

支持 `.mdx` v1.2/v2.0、UTF-8/UTF-16、zlib/LZO 压缩和常见的 `Encrypted=2` key-info 混淆。`@@@LINK` 会保存为轻量别名，不重复存储大段 HTML；词条 HTML 会先消毒，配套 CSS 会限定到当前词典，避免污染应用界面。附近的 `.mdd` 会作为图片/音频资源解包。

密码加密的 `Encrypted=1` 目前无法导入。目录外的文件可直接运行：

```bash
npm run dict:import -- "D:\\path\\词典.mdx"
```

## 推荐词典

| 词典 | 类型 | 说明 |
| --- | --- | --- |
| 明鏡国語辞典 第二版 | 日日 | 释义精准，语法说明详尽，首选 |
| 新明解国語辞典 第八版 | 日日 | 释义有个性，例句好 |
| 大辞林 / 大辞泉 | 日日 | 收词量大，百科向 |
| JMdict | 日英 | 开源，覆盖面广，含词性与用法标记 |
| 中日辞典 / CC-CEDICT 系 | 日中 | 中文释义 |
| NHK日本語発音アクセント新辞典 | 声调 | 标准声调数据 |
| Kanjium Pitch Accents | 声调 | 覆盖量大的声调补充 |
| JPDB / BCCWJ 频率表 | 词频 | 用于「仅生词注音」和释义排序 |
| KANJIDIC | 汉字 | 单字详解 |

多部词典可同时导入。在「词典管理」里可以调整**优先级**（决定释义展示顺序）和**启用状态**。

## 从哪里获取

Yomitan 官方索引了一批免费词典，收录在其项目文档中；`jmdict-yomitan` 等社区项目会定期发布构建好的 zip。受版权保护的商业词典（明鏡、新明解等）请自行从合法渠道获取。

## 没有词典会怎样

分词、词性标注、活用还原、助词分析、振假名、AI 问答**全部照常工作**，只是词条释义、声调和词频会是空的。
